# Keyword Extraction

## Description

Keyword Extraction is a simple Natural Language Processing application that identifies important words from a given paragraph.

The application removes common words and finds the most frequently occurring words.

## Technology Used

- Python
- Regular Expressions
- Collections
- Natural Language Processing

## Requirements

Python 3.x

## Installation

No external libraries are required.

## How to Run

1. Open the project folder in VS Code.
2. Open the terminal.
3. Run:

python app.py

4. Enter a paragraph.
5. The application displays the top five keywords.

## Example

### Input

Python is a popular programming language. Python is easy to learn.

### Output

Top Keywords:

python - 2 time(s)
popular - 1 time(s)
programming - 1 time(s)
language - 1 time(s)
easy - 1 time(s)

## Conclusion

This project demonstrates a basic Natural Language Processing technique for extracting important keywords from text.
